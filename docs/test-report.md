### 시험 중 고친 것

| 문제 | 원인 · 고침 |
| --- | --- |
| 자동 탐색 때 Nav2 가 안 뜸 (`No critics defined for FollowPath`) | `navigation_launch.py` 는 네임스페이스를 씌우지 않음 → `PushROSNamespace` 로 감쌈 |
| 자동 탐색이 같은 목표를 1초에 수십 번 보내며 제자리 | explore_lite 가 도착한 frontier 를 blacklist 에 넣지 않음 → `explore.cpp` 한 줄 고침 (로컬 패치) |
| patrol_node 시작 직후 죽음 | 벽 근처 칸 계산의 배열 자르기 범위 오류 |
| 상자가 있어도 경보 없음 | 넓이를 "맞은 칸 수"로 계산 → LiDAR 는 겉면만 보므로 너무 작음 → 감싸는 상자 넓이(두께 최소 0.1 m) |
| 사라진 것이 감지 안 됨 | 그 방향 빛이 모두 `max_range`(3.5 m) 밖에서 돌아와 버려짐 → 먼 곳에서 돌아온 빛도 3.5 m 까지는 증거로 |
| 벽을 따라 "사라진 것" 오탐 | 비스듬히 스치는 빛이 지도 벽 칸을 지남 → 입사각 25° 미만 제외 + 끝점 앞 여유를 수직 거리로 |
| 경보 상자가 처음 본 면만큼 작음 | 갱신 때 상자를 합쳐 키움 (2 m 까지) |
| 멈춤·확인 이동을 누르면 patrol_node 가 죽음 | rclpy `ClientGoalHandle` 의 `==` 가 다른 타입과 비교하면 예외 → `isinstance` 로 비교. 취소한 goal 의 늦은 콜백이 새 goal 을 지우던 문제도 고침 |
| Nav2 없을 때 "보내기"가 조용히 사라짐 | 30초 동안 "Nav2 없음"으로 기다림 |
| 비상정지가 경비 순찰을 못 멈춤 | 순찰 goal 은 서버가 보낸 것 → 비상정지가 `/fleet/patrol_cmd` 로 모든 로봇 멈춤 |
| patrol_node 가 죽어도 모드는 "경비" 그대로 | 서버 감시 스레드가 다시 띄움 + 모드 칩 경고 |
| 경보 상세·상태 표 버튼이 눌리지 않을 때가 있음 | 1초·3초마다 통째로 다시 그려 버튼이 바뀜 → 내용이 바뀔 때만 다시 그림 |
| 경보 링크(`#alert-N`)를 같은 페이지에서 열면 안 바뀜 | `hashchange` 처리 |
| 사라진 것을 기준 지도에 반영해도 뒷면이 남음 | 상자에 붙어 있던 벽 칸(0.5 m 안)까지 지움 |
| 경보·토스트에 로봇 id 표시 | 이름으로 |
| 진동 호출 콘솔 오류 | 화면을 누른 적이 있을 때만 |

### 실제 로봇에서 남은 확인

- 시작 위치를 잰 값으로 합친 지도가 얼마나 맞는지 (각도 오차에 민감)
- 실제 Nav2 로 순찰 경로를 끝까지 도는지, 확인 이동이 경보 앞에 서는지
- 실제 LiDAR(TurtleBot3 LDS, Pinky RPLIDAR)의 잡음·유리·검은 물체·사람에 대한 오탐 수준 → 감지 설정 기본값 조정
- 여러 로봇이 같은 곳을 볼 때 등급 올리기가 실제로 맞는지

시험용 지도·순찰 설정·경보 DB·로그는 프로젝트에서 뺐고 `config/fleet.json` 은 시험 전 상태로 되돌렸습니다. explore_lite 로컬 패치(`ros2_ws/src/m-explore-ros2/explore/src/explore.cpp`)는 남겨 두었습니다.
